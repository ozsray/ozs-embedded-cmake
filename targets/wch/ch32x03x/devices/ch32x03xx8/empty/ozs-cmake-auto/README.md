# ozs-cmake-auto

本目录用于放置需要由当前工程的 CMake 自动收集的 C 源文件和头文件，支持多级子目录。

- `.c` 文件：递归收集并追加到工程的源码清单，参与编译。
- `.h` 文件：递归收集，并将其所在目录加入头文件搜索路径；头文件本身不单独编译。
- 本目录根目录也会加入头文件搜索路径。
- 新增或删除 `.c`、`.h` 文件后，构建时会检查文件列表变化，并按需重新生成构建系统。
- 工程原有的手动源码清单和头文件搜索路径继续生效。

例如，放入 `a/a.c` 和 `a/a.h` 后，`a.c` 会自动参与编译，`User/main.c` 可以通过 `#include "a.h"` 或 `#include "a/a.h"` 使用其头文件。

自动收集仅匹配 `.c` 和 `.h`，本 README 等 `.md` 文件不会被收集或参与编译。保留本 README 也使 Git 能够跟踪此目录。
